# Module III — CISCE Resource Pack on Foundational Literacy and Numeracy (FLN)

**Full title:** *Engaging in Enriching Experiences for Foundational Literacy and Numeracy (FLN)*
**Publisher:** CISCE / RDCD, New Delhi — November 2022
**Source file:** `docs/Module-III.pdf` (240 pages)
**Target audience:** Teachers and teacher educators, Preschool I → Class III (ages 3–9)
**Framework:** NIPUN Bharat Mission (NEP 2020)

---

## What This Document Is

A **teacher's activity toolkit** — 240 pages of ready-to-use classroom resources built around 3 Developmental Goals from the NIPUN Bharat framework. It is the practical, hands-on complement to Modules I and II (which cover theory and learning outcomes).

Part of a 3-module series:
- **Module I:** Exploring FLN (theory, components, assessment framework)
- **Module II:** Creating an Enabling Environment for FLN (teaching-learning processes, class-wise)
- **Module III:** Engaging in Enriching Experiences for FLN ← this document

---

## The 3 Developmental Goals

| Goal | Focus |
|---|---|
| **DG 1** | Children maintain good **health and well-being** |
| **DG 2** | Children become **effective communicators** (language & literacy) |
| **DG 3** | Children become **involved learners** (numeracy & cognitive) |

Each activity, worksheet, rhyme, and rubric in this module is designed to serve one or more of these three goals.

## Key Terms Defined in This Document

| Term | Definition |
|---|---|
| **FLN** | Foundational Literacy and Numeracy |
| **NIPUN Bharat** | National Initiative for Proficiency in Reading with Understanding and Numeracy |
| **ECCE** | Early Childhood Care and Education |
| **Fine Motor Skills** | Coordination of small muscles — hands, fingers, eyes |
| **Gross Motor Skills** | Control of large muscles — walking, running, jumping |
| **Phonological Awareness** | Ability to recognise and work with sounds in spoken language |
| **Formative Assessment** | In-process evaluation methods used during learning |
| **Rubrics** | Assessment tool indicating achievement criteria across components |
| **Shared Reading** | Teacher reads a big book aloud; whole class participates |
| **Read Aloud** | Teacher reads engaging text aloud; varies pitch, tone, pace |
| **Sight Words** | Commonly used words children memorise by sight |
| **Blending** | Combining sounds rapidly to represent a word |
| **Holistic Development** | Development of intellectual, mental, physical, emotional and social abilities |
