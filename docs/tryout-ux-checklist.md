# Tryout editor checks

Question edits, including new questions after their first edit, are passed to the lesson-plan draft immediately. Back and Done return to question types; neither discards edits. Lesson-plan saving and publishing still use the existing parent workflow.

- Add an MCQ, enter text/options, use Back, and reopen it. Check the values remain.
- Edit a question, switch to another lesson-plan tab, and return. Verify the changes remain without clicking Done.
- Edit question 2 and delete question 1. Continue typing and verify only the remaining question changes.
- Remove an MCQ option before the correct option. Verify the same answer remains correct. Removing the correct option clears the selection; select a replacement.
- Use Tab and Enter to open questions and reach delete, Back, and Done controls.
- At phone and desktop widths, check readable question descriptions, wrapping controls, and access to the full editor through the lesson-plan scroll area.
- Expand “AI question generator” in the menu to access generation settings. Check these disappear during editing, and question editing/deletion is disabled while generation runs.
