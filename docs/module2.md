## Core Purpose

> "An enabling environment in the classroom plays a key role in supporting children's learning and development. Children learn and develop best in an environment that is caring and supportive, that supports their individual needs, while allowing them to play, explore and discover."

## The 3 Developmental Goals (All Levels)

| Goal | Code | Focus |
|---|---|---|
| **DG 1** | HW | Children maintain good **Health and Well-being** |
| **DG 2** | EC | Children become **Effective Communicators** (language & literacy) |
| **DG 3** | IL | Children become **Involved Learners** and connect with their environment (numeracy & cognitive) |

Each level covers all three DGs. The same key competencies repeat across levels, with LOs becoming progressively more complex.

## Learning Outcome Coding System

Each LO has a unique code for easy identification:

| Pattern | Meaning | Example |
|---|---|---|
| `HW [n].[#]` | DG1 LO, class n, outcome # | `HW 1.3` = PS-I, DG1, LO 3 |
| `ECL[n]-[#]` | DG2 Language LO, class n | `ECL1-1.1a` = PS-I, First Language, LO 1a |
| `IL[n].[#]` | DG3 (general) LO, class n | `IL1.1` = PS-I, DG3, LO 1 |
| `ILM [n].[#]` | DG3 Mathematics LO | `ILM 5.29` = Class II, Math LO 29 |

Class numbering: PS-I=1, PS-II=2, PS-III=3, Class I=4, Class II=5, Class III=6.

## Key Competencies by Developmental Goal

### DG 1 — Health & Well-being (all levels)

| Competency | Description |
|---|---|
| Awareness of self | Physical, emotional, identity |
| Development of positive self-concept | Confidence, self-esteem, choices |
| Self-regulation | Managing emotions, impulse control |
| Decision making and problem solving | Age-appropriate decisions and conflict resolution |
| Development of pro-social behaviour | Sharing, caring, cooperation, sensitivity to diversity |
| Healthy habits, hygiene, sanitation, self-protection | Safety, nutrition, personal hygiene |
| Development of gross motor skills | Running, jumping, climbing, dancing, sports |
| Development of fine motor skills and eye-hand coordination | Threading, colouring, clay, scissors, writing |
| Participation in games (individual and team) and sports | Team spirit, following rules, leadership |

### DG 2 — Effective Communicators

Three sub-areas, each with its own LO codes:

**Talking and Listening (First Language)**
- Listening comprehension, creative self-expression and conversation, language and creative thinking, vocabulary development, conversation and talking skills, meaningful uses of language

**Reading with Comprehension**
- Bonding with books, print awareness and meaning making, pretend reading, phonological awareness, sound-symbol association, prediction using prior knowledge, independent reading for pleasure

**Writing with Purpose**
- Early literacy skills, writing for self-expression, knowledge of letters/sounds, inventing spellings, conventional writing, writing rhyming words, meaningful sentences (naming words + action words), messages, lists, greetings

### DG 3 — Involved Learners

Two sub-areas:

**Sensory & Cognitive Development**
- Sensory: Sight, Sound, Touch, Smell, Taste
- Cognitive: Observation, Identification, Memory, Matching, Classification, Patterns, Sequential Thinking, Creative Thinking, Critical Thinking, Problem Solving, Reasoning, Curiosity, Experimentation, Exploration
- Environment concepts: Natural (animals, fruits, vegetables, food), Physical (water, air, seasons, sun, moon, day/night), Social (myself, family, transport, festivals, community helpers)

**Foundational Numeracy**
- Concept Formation: colours, shapes, distance, measurement, size, length, weight, height, time, spatial sense, one-to-one correspondence
- Number Sense: count and tell how many, numeral recognition, sense of order (counting ahead up to 10)
- Number Operations: addition, subtraction, multiplication, division
- Measurement: length, mass, volume, temperature
- Shapes: 2D shapes, 3D shapes, straight/curved lines, plain/curved surfaces
- Data Handling, Pattern Recognition, Calendar Activity, Use of Technology

## Pedagogical Philosophy

1. **Enabling Environment First** — the physical and emotional classroom environment is a pre-condition for learning; all activities assume a print-rich, interest-area-equipped, caring space.
2. **Integrated, Not Siloed** — activities for one LO address multiple LOs across all 3 DGs simultaneously.
3. **Play-Based Learning** — circle time, free play, pretend play, and game-based activities are the primary vehicles, especially at preschool level.
4. **Multilingual Acceptance** — children should converse and engage in the language they are most comfortable in; bilingual and home language use is explicitly encouraged.
5. **Formative Assessment Only** — guiding questions in Column III are for in-the-moment teacher observation, not formal tests. Assessment is holistic, term-by-term, and progressive.
6. **Inclusion Built-In** — every level explicitly includes outcomes and strategies for children with special needs, diverse cultural backgrounds, and first-generation learners.

### Specific Uses for EEC

1. **LO-aligned quiz/homework generation** — each LO has a guiding assessment question that can be adapted as an EEC AI tutor prompt
2. **Difficulty progression mapping** — LO codes (HW 1.x → HW 6.x) give a ready-made 6-level difficulty ladder for any competency
3. **Teacher observation scoring** — Column III guiding questions map directly to EEC's offline scoring checklist (teacher rates 1–5)
4. **Mastery Engine triggers** — the "term-wise, progressive" assessment philosophy aligns with EEC's spaced repetition and mastery tracking
5. **Student Development Profile** — the 6-level progression of DG1 (self-regulation → leadership) maps onto EEC's Social-Emotional development category
6. **Content for AI tutor modes** — each LO + pedagogical process is a ready-made prompt source for `explain`, `quiz`, `homework_help`, and `differentiated_plan` modes
7. **At-risk identification** — guiding questions like "Does the child still ask for instructions to be repeated?" are at-risk indicators that map to EEC's at-risk detection system
